# ちょっとだけ庭

水をあげて少しだけ花を育て、自分の庭を少しずつ作っていく小さなWebアプリです。

## 現在の仕様
- 水は20分ごとに1回復、最大5
- 開花後、日付が変わるとランダムで次の花が1種類決まる（同じ花も出る）
- 未開花の花は日付をまたいでも同じ鉢で続きから育てられる
- 花ごとに開花に必要な水量が違う
- 開花した花は庭に追加
- 庭の花はドラッグして並べ替え可能
- 1日1回、庭の記録をアルバムに保存
- 花のコレクションを確認可能
- 水やり時に「ぽたっ」「ぷるん」、開花時に「ぽんっ」「キラキラ」演出
- 記録はブラウザのlocalStorageに保存

## 注意
「庭の写真」は背景画像と花をCanvasへ合成して、ブラウザ内に記録します。

データを消さずにアップデートするため、localStorageのキー `chotto_dake_garden_v1` は変更しないでください。
将来データ形式を変更する場合は、migration（旧データを新形式へ移す処理）を入れてください。
